# Terie Carstarphen Portfolio

A one-page Next.js, TypeScript, and Tailwind CSS portfolio for Terie Carstarphen, an AI training data specialist, LLM evaluator, multimodal annotator, and quantitative domain expert.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## GitHub Pages

This project includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.
After the repository is pushed to GitHub, enable Pages with **Source: GitHub
Actions** in the repository settings. The landing page URL will be:

```text
https://techxnline.github.io/myportfolio/
```
